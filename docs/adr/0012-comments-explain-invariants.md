# 0012 注释解释不变量，不记录施工历史

- **Status**: Accepted（Wave 6 起 AGENTS.md 不再按任务编号叙述）
- **对应宪法条款**: C12

## 决策

代码注释应该解释：为什么这个顺序不能改、为什么这份状态必须共享、
删掉这个约束会出什么故障、哪条 ADR 记了这个决定。

`T44`、`T48`、`S7` 这类历史任务号**不应成为理解代码的前置条件**。
任务历史留在 `docs/plans/` 与 git 里，稳定决策进 ADR。

## 为什么

一个新人读到 `// T48:Run 提前到模型解析前创建` 时，真正需要的信息是**为什么提前** ——
「provider 配错时也要留下台账行，否则 routing 失败会变成查不到的 Run」。
编号只告诉他去哪儿考古。

## 今天到哪一步

- AGENTS.md 已改写为按模块叙述，不再用 T/S 编号组织（Wave 6）。
- 代码里仍有一批 `T48:` / `S27:` 前缀的注释。**保留**是有意的：它们后面都跟着真正的理由，
  编号只是出处。新写注释不要再加编号；改到那一行时可以顺手去掉。

## 代价

写注释更费一点 —— 要想清楚"删掉会怎样"，而不是记一句"这是 T48 做的"。

## 怎么验证

§13.4 人类阅读验收：「无需理解 T/S 历史任务编号」。
